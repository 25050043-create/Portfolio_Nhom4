# Portfolio cá nhân — Pastel Editorial - Tóm tắt về website em làm

## Cấu trúc

- `index.html`: nội dung semantic và các section.
- `css/style.css`: layout responsive, palette, dark mode styles, hover và animation. - Sử dụng công cụ online để nén lại
- `js/script.js`: menu mobile, dark mode, lọc dự án, reveal on scroll, kiểm tra form.
- `images/`: nơi thêm ảnh
